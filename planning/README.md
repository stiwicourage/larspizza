# Lars' Pizza planning

Dette katalog samler projektets plan, MVP-afgrænsning og backlog, så arbejdet kan styres direkte i repoet.

## Filer

- `mvp-plan.md` - mål, arkitektur og implementeringsrækkefølge for MVP
- `backlog.md` - opgaver opdelt i rækkefølge med status og næste fokus

## Arbejdsprincipper

- Hold MVP lille og mobil-først
- Behold GitHub Pages-frontend under `docs/`
- Hold PHP API, MySQL og mail-logik adskilt fra frontend
- Brug backloggen som sandhed for rækkefølge og scope
